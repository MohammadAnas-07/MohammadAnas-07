## Projects

### Saga Fulfillment Engine

A distributed order fulfillment system built around the Saga pattern to coordinate multi-step workflows across services.

The project focuses on handling failures in distributed transactions, coordinating services through asynchronous events, and compensating previously completed operations when a workflow cannot be completed successfully.

**Focus:** Java · Spring Boot · Microservices · Apache Kafka · Saga Pattern · Docker

Source: https://github.com/MohammadAnas-07/saga-fulfillment-engine

### Ledger Wallet API

A backend wallet and ledger API built around double-entry bookkeeping and transactional consistency.

Supports deposits, withdrawals, and transfers while handling concurrent updates through optimistic and pessimistic locking. The system also uses idempotency keys to prevent duplicate money movements and publishes transaction events through Kafka.

**Focus:** Java · Spring Boot · PostgreSQL · Apache Kafka · Docker · Concurrency · Idempotency

Source: https://github.com/MohammadAnas-07/ledger-wallet-api
